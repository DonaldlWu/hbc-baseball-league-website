# 排行榜積分與排序規則

## 積分制度

| 結果 | 積分 |
|------|------|
| 勝 (Win) | **3 分** |
| 和 (Draw) | **1 分** |
| 敗 (Loss) | **0 分** |

---

## 排序優先序

同積分時依序套用下列規則，直到分出高下為止：

### 第 1 順位：積分（高者優先）

```
積分 = 勝 × 3 + 和 × 1
```

### 第 2 順位：勝率（高者優先）

```
勝率 = 勝 ÷ (勝 + 敗)
```

> 和局不計入勝率分母。例：2 勝 1 和 2 敗 → 勝率 = 2 ÷ (2+2) = 50.0%

### 第 3 順位：同積分＋同勝率群組 → 互打積分（高者優先）

積分**與**勝率均相同的球隊形成一個並列群組，計算群組內各隊彼此之間已完賽場次的**對戰積分**（勝3、和1、敗0）。

> 只計算**群組內**球隊之間的對戰，群組外比賽不列入。

### 第 4 順位：互打失分（少者優先）

群組內對戰中，平均每場**失分**較少者排名較前。

### 第 5 順位：整體均失（少者優先）

若群組內對戰完全未分出高下（例如：群組成員彼此從未交手），改以**整體賽季均失**（`平均失分 = 總失分 ÷ 已賽場數`）排序，失分較少者優先。

---

## 計算欄位說明

| 欄位 | 說明 | 計算方式 |
|------|------|----------|
| 積分 | 累計積分 | 勝×3 + 和×1 |
| 勝率 | 勝場比率 | 勝 ÷ (勝+敗)，和局不計 |
| 勝差 | 距第一名的差距 | (首位勝 − 本隊勝 + 本隊敗 − 首位敗) ÷ 2 |
| 平均失分 | 每場平均失分 | 總失分 ÷ 已賽場數 |
| 平均得分 | 每場平均得分 | 總得分 ÷ 已賽場數 |

## 範例

### 範例 A：互打有勝負（MIRACLE vs HOLYBAT，2026 賽季）

| 球隊 | 勝 | 敗 | 和 | 積分 | 勝率 |
|------|-----|-----|-----|------|------|
| MIRACLE | 2 | 5 | 0 | 6 | 28.6% |
| HOLYBAT | 2 | 5 | 0 | 6 | 28.6% |

積分相同、勝率相同 → 進入並列群組。

互打記錄：MIRACLE 15:11 HOLYBAT（2026-07-04）  
→ 互打積分：MIRACLE 3 分、HOLYBAT 0 分  
→ **MIRACLE 排名較前（第 15）、HOLYBAT 較後（第 16）**

### 範例 B：無互打記錄（台大經濟OB vs 政大Mechanics，2026 賽季）

| 球隊 | 勝 | 敗 | 和 | 積分 | 勝率 | 均失 |
|------|-----|-----|-----|------|------|----|
| DH戰將 | 0 | 5 | 0 | 0 | 0.0% | 10.8 |
| 台大經濟OB | 0 | 6 | 0 | 0 | 0.0% | 11.8 |
| 政大Mechanics | 0 | 1 | 0 | 0 | 0.0% | 15.0 |
| 台大醫學院棒 | 0 | 6 | 0 | 0 | 0.0% | 18.3 |

積分相同、勝率相同 → 四隊並列群組。  
群組內無任何已完賽互打場次 → 退至第 5 順位：整體均失（升冪）  
→ **DH戰將（10.8）→ 台大經濟OB（11.8）→ 政大Mechanics（15.0）→ 台大醫學院棒（18.3）**

## 技術實作

邏輯位於 `src/lib/standingsCalculator.ts`：

- `calculatePoints(wins, draws)` — 計算積分
- `calculateWinRate(wins, losses)` — 計算勝率
- `calculateGamesBehind(leader, team)` — 計算勝差
- `resolveGroupTiesWithGames(sorted, games)` — 有賽事資料時的並列排名（2026+ 賽季）
- `resolveGroupTiesWithTiebreakRank(sorted)` — 手動並列排名（2025 賽季，依 `tiebreakRank` 欄位）
- `calculateStandings(teams, streaks, specialTags, games)` — 完整排名計算入口
